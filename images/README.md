Tips
- Download from Pexels, rename to the file name above, and save as .jpg.
- Resize to about 1600 px wide (or smaller) so the page loads quickly on phones.
- Prefer real, warm, South Asian faces and settings where you can.
- Pexels photos are free to use, but check each photo's page for any restrictions, and avoid photos that show a recognisable brand.
